# 🎬 CineSuggest — Movie Discovery Platform

A modern, visually engaging movie discovery interface designed to make exploring movies more enjoyable. CineSuggest brings together trending movies, genres, ratings, and movie information in a clean, dark-themed interface.

## 📌 About the Project

CineSuggest is a frontend web development project built to explore the fundamentals of creating an attractive and user-friendly movie discovery platform.

The interface features a curated movie collection, a trending movie showcase, genre categories, and individual movie cards displaying essential information.

The primary goal of this project is to build a clean user experience while strengthening practical skills in frontend development.

## ✨ Features

- **Modern Navigation Bar** — Easy access to different sections of the platform.
- **Trending Movie Showcase** — Highlights a featured movie with its overview and details.
- **Genre Categories** — Browse movies across genres such as Action, Comedy, Drama, Sci-Fi, Thriller, Horror, Animation, and Romance.
- **Movie Collection** — Displays movie posters in an organized card-based layout.
- **Movie Ratings** — Shows ratings alongside movie titles.
- **Release Information** — Displays movie release years.
- **Interactive UI Styling** — Hover effects and transitions for a more engaging experience.
- **Dark Theme** — A consistent dark interface with blue accents.

## 🚀 Getting Started

Follow these steps to run CineSuggest locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/CineSuggest.git
```

### 2. Navigate to the project directory

```bash
cd CineSuggest
```

### 3. Run the application

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.
